# 工作区批量归档与目录迁移

## 用户需求与确认
用户原始请求：新增支持工作区内批量归档，和工作区迁移（变更目录）。
本轮澄清用户选择「扩展当前插件」，并确认：批量归档指选中同一工作区多个会话归档；迁移指将工作区及会话关联到新目录，保留历史，不搬动项目文件。

## 范围
在 dsh-plugin-enhance 中提供工作区管理入口，复用 DSH 服务。支持多选归档与目录迁移；保持中英文文案一致。不要修改 DSH 安装包，不提交、发布或安装插件。

## 基线
基于 26a7c858ec05062b71cb3adeecf6939a98935fd8。README.md 描述现有插件更新能力，index.js 提供 Typert owner 网关及更新工具，client.source.js 注册增强管理标签。当前没有工作区管理代码或项目知识入口。
分支 workspace-batch-archive-migrate，当前独立 worktree 为唯一变更材料位置。

## 约束与调查
优先复用原生 API，不直接改私有数据库、历史事件。需要核对原生工作区路径与会话 cwd 可变性、运行任务保护、迁移目标占用及失败行为。
当前 Host 文档 docs/subsystems/workspace.zh.md 指出工作区 path 为创建时确定的只读属性，归档由 workspaceRegistry 提供且默认拒绝活跃会话；需继续核对源码判断迁移能力。

## 结果判据
能够在同一工作区选择多个会话归档并看到逐项结果；目录迁移保留历史及归属并影响后续工作目录。具体验收与支持边界由源码调查后的 spec 明确。
